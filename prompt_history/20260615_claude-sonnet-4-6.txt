原因が分かりました。**CommonMark の太字判定ルール**と日本語の約物の組み合わせによる問題です。

## 原因

CommonMark の仕様では、**閉じる `**`** が有効と認識されるには「右フランキング・デリミタ」である必要があります。

> 閉じ `**` が **Unicode 句読点文字の直後** にある場合、その `**` の後ろが **空白か句読点でなければ**、閉じとして認識されない。

`「」（）` はすべて Unicode カテゴリ **Ps/Pe (Opening/Closing Punctuation)** に分類されます。

```
**「Mermaid（マーメイド）」**のようになってしまいます
                              ↑              ↑↑
                              Pe(句読点)      後ろが「の」(ひらがな = 非句読点・非空白)
                                             → CommonMark が閉じ ** と判断しない
```

`」**` の後ろが `のように` (ひらがな) なので、閉じ `**` と認識されず、太字にならないのが仕様通りの動作です。

## 回避策（コンテンツ側）

**① `**` の後に半角スペースを挿入（最も確実）**
```markdown
**「Mermaid（マーメイド）」** のようになってしまいます
```

**② ゼロ幅スペース（U+200B）を挿入（見た目は変わらない）**
```markdown
**「Mermaid（マーメイド）」**​のようになってしまいます
```
（`」**` と `の` の間に U+200B を挟む）

**③ HTML タグで代替（ただし現状のレンダラーが許可する場合のみ）**
```html
<strong>「Mermaid（マーメイド）」</strong>のようになってしまいます
```
