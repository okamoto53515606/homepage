## 意見

### 1. `use server` 廃止 → `/api/xxx` fetch 化は技術的に正しい

AWS公式ドキュメントで確認しました:

> **If you use `PUT` or `POST` methods with your Lambda function URL, your users must compute the SHA256 of the body and include the payload hash value of the request body in the `x-amz-content-sha256` header when sending the request to CloudFront.** Lambda doesn't support unsigned payloads.

Server Actionsはブラウザが内部的にPOSTを送信するため、`x-amz-content-sha256`ヘッダーを付与できません。一方、`fetch()`なら以下のようにヘッダーを制御可能です:

```js
const body = JSON.stringify(data);
const hash = await crypto.subtle.digest('SHA-256', new TextEncoder().encode(body));
const hashHex = Array.from(new Uint8Array(hash)).map(b => b.toString(16).padStart(2, '0')).join('');
fetch('/api/xxx', {
  method: 'POST',
  headers: { 'x-amz-content-sha256': hashHex },
  body,
});
```

RSCの脆弱性リスク低減（CVE-2024-34350, 34351等）の観点からも賛成です。

### 5. WAF IP制限 + Cognito 2FA の2本立ては良い設計

- **WAF**: CloudFrontのエッジでIP制限 → 非許可IPは即ブロック（低コスト・高速）
- **Cognito 2FA**: IPが通過しても認証 + 2FAが必要

**結論: Proxy Lambdaは不要です。CloudFront OACでStripe webhookはそのまま動きます。**

理由を説明します：

### CloudFront OAC の POST 処理

AWS公式ドキュメントによると、CloudFront OAC は POST/PUT/DELETE/PATCH を完全にサポートしており、**CloudFront自身がリクエストボディのSHA256ハッシュを計算**してSigV4署名に含めます。

つまり、フローは：
```
Stripe → POST → CloudFront → (OACがbody hashを自動計算 + SigV4署名) → Lambda Function URL
```

クライアント側（=Stripe）が `x-amz-content-sha256` ヘッダーを送る必要はありません。AWS公式ドキュメントにも「viewerがこのヘッダーを含めない場合、CloudFrontがハッシュを計算する」と明記されています。

### `fetchWithSigning()` との関係

先行実装した `fetchWithSigning()` はブラウザ→CloudFront間で `x-amz-content-sha256` を送りますが、これはCloudFrontの動作にとってはオプショナルです。CloudFrontは受け取ったかどうかに関わらず、自身でハッシュを計算してOrigin（Lambda）への署名に使います。

### Stripe webhook に必要なCloudFront設定

blueprintに追記すべきは proxy Lambda ではなく、以下のCloudFront設定です：

| 設定項目 | 内容 |
|---------|------|
| AllowedMethods | GET, HEAD, **POST**, OPTIONS |
| Cache Policy | `CachingDisabled` |
| Origin Request Policy | `stripe-signature` ヘッダーを転送 |
| WAF | `/api/stripe/webhook` はIP制限対象外にする |

`stripe-signature` ヘッダーさえ転送されれば、既存の `stripe.webhooks.constructEvent()` による署名検証もそのまま動作します。
