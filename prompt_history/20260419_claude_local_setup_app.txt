### 2. bashrc の AWS 環境変数 — 削除してください

**削除すべき理由：**

| 変数 | 問題 |
|------|------|
| `AWS_PROFILE=okamo` | SDK がプロファイル経由で認証しようとする。.env に書いた `AWS_ACCESS_KEY_ID`/`AWS_SECRET_ACCESS_KEY` と競合する可能性がある |
| `AWS_REGION=us-east-1` | プロジェクトは `ap-northeast-1` を使う。CDK の `--region` 指定より環境変数が優先されるケースがあり、意図しないリージョンにデプロイされるリスク |

**推奨フロー：**
- bashrc から `AWS_PROFILE` と `AWS_REGION` を削除
- セットアップアプリが .env に `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `AWS_REGION=ap-northeast-1` を書き込む
- CDK / AWS SDK は .env（dotenv 経由）から読み取る → セットアップ画面が唯一の設定ソース

これで「セットアップ画面で入力した値が常に使われる」状態になり、非エンジニアユーザーが bashrc を触る必要もなくなります。
